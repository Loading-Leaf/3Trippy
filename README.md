# 3Trippy (トリッピー 3マッチパズル)

![3Trippy Banner](sprite/title.png)

かわいいキャラクター「トリッピー」と一緒に世界一周の旅へ出かけよう！  
誰でも手軽に楽しめる爽快3マッチパズルゲームです。

---

## 🎮 プレイ方法

利用環境に合わせて3通りのプレイ方法が用意されています。

### 1. EXEファイルでプレイ（Windows向け / おすすめ）
Pythonなどの実行環境をインストールすることなく、ダウンロードしてすぐに遊ぶことができます。

1. **実行ファイルの取得**
   - `dist/3Trippy.exe`（または Releases からダウンロードした `3Trippy.exe`）を用意します。
2. **ゲームの起動**
   - `3Trippy.exe` をダブルクリックして起動します。

> **💡 Windowsセキュリティ警告が表示される場合**  
> 未署名の実行ファイルのため、起動時に「WindowsによってPCが保護されました」等の警告が表示される場合があります。  
> 以下の手順で起動してください：  
> 1. ダイアログ内の **「詳細情報」** をクリック  
> 2. 右下に表示される **「実行」** ボタンをクリック

## 🕹️ ゲームのルール & 操作方法

### 操作方法
- **ピースの移動**: マウスでピースを上下左右にスワイプ（ドラッグ）して入れ替えます。

### 基本ルール
- **3マッチ消去**: 同じ種類のピースを縦または横に **3つ以上** 揃えると消去され、スコアを獲得できます。
- **スコア加算**:
  - 3ピース消去: 80点
  - 4ピース消去: 160点
  - 5ピース消去: 240点
  - **コンボボーナス**: 連鎖が発生するとコンボ数に応じてさらにボーナス加算（+40点〜）！
- **特殊ピース**:
  - 4マッチ: **ライン消去ピース** (縦または横一列を消去)
  - L字 / T字マッチ: **クロス消去ピース** または **3x3爆弾ピース**
  - 5マッチ: **カラーボム** (同色のピースを一括消去)

## 🛠️ EXEファイルのビルド方法 (PyInstaller)

自分で `.exe` 実行ファイルをビルドする場合は、PyInstaller を利用します。

### 1. 必要なパッケージのインストール
```bash
pip install pygame pyinstaller
```

### 2. ビルドの実行
プロジェクトルートディレクトリで以下のコマンドを実行します。

```bash
pyinstaller --noconfirm 3Trippy.spec
```

ビルドが完了すると、`dist` ディレクトリ内に **`3Trippy.exe`** が生成されます。  
(`3Trippy.spec` により、画像・音声・フォント等のリソースが単一のexe内に同梱されます)

## 📁 プロジェクト構成

```
3Trippy/
├── main.py              # メイン処理・ゲームループ・UI描画
├── board.py             # パズルボードのロジック（マッチ判定・落下・コンボ処理）
├── config.py            # 設定値・エリア進行表・リソースパス管理
├── audio_manager.py     # BGM/SEサウンド再生管理
├── generate_sounds.py   # 効果音・BGM自動生成スクリプト
├── generate_assets.py   # スプライト自動生成スクリプト
├── 3Trippy.spec         # PyInstaller ビルド用設定ファイル
├── requirements.md      # ゲーム仕様書
├── fonts/               # フォントファイル
├── sounds/              # 効果音・BGMファイル
├── sprite/              # 画像アセット（ピース、背景、タイトル等）
└── .github/workflows/   # GitHub Actions (Pygbag Webビルド用デプロイ設定)
```
